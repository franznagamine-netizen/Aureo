Áureo 3.2.10

Sube los archivos de este ZIP a la misma raíz del repositorio Aureo. No cambies la dirección ni desinstales la app.

Al abrir desde el mismo dispositivo y navegador, se recupera aureoV16 y se conserva el catálogo, incluidos los conceptos y subgrupos eliminados. Antes de modificar los datos se conserva una copia local anterior a la actualización.

1. Abre Respaldo y exporta el respaldo a Archivos del iPhone.
2. Detalle contiene saldos, pagos e inversión pendientes. Usa − y + para ajustar celdas (60–140%). La preferencia se guarda.
3. Dashboard > Registrar inversión: registra aportes pasados sin descontar disponible, o elige realizar una inversión pendiente para reducir esa celda y añadir el aporte en una sola operación. Actualiza también el saldo de dinero en Detalle al valor que realmente queda.
4. La meta compara lo ya invertido, lo pendiente y lo que falta asignar. El anillo muestra solo lo realizado.
5. Edita o pon 0 eligiendo Desde/Hasta para limitar los meses afectados.

Al editar o eliminar un aporte histórico, no se modifican las celdas de Detalle. El registro refleja aportes, no rentabilidad ni valor de mercado.

El respaldo JSON contiene datos personales. No lo subas al repositorio público.
