# Áureo V1.3

Reemplaza el `index.html` de la raíz del repositorio de GitHub Pages.

## Novedades de esta versión

- Buscador de conceptos y subgrupos en la vista anual.
- Vista macro activada por defecto.
- Vista detalle con conceptos editables.
- Semáforo presupuestal:
  - Verde: dentro del presupuesto.
  - Ámbar: consumo igual o superior al 85%.
  - Rojo: presupuesto superado.
- Encabezado y primera columna congelados.
- Animaciones suaves en KPIs, anillo y barra de progreso.
- Totales mensuales por sección y subgrupo.
- Subgrupos editables y eliminables.
- Movimiento de conceptos entre subgrupos.
- Migración automática desde datos guardados por V1.0, V1.1 y V1.2.
