# Áureo 3.2.9

La meta anual se edita en Dashboard y se compara con la suma de los montos mensuales de Inversión en Detalle, incluidos meses futuros. Se identifica como inversión registrada y prevista.

Detalle muestra una sola fila por concepto de inversión, sin repetir subgrupos ni filas Invertido. Toca el monto del mes para editarlo.

El Dashboard, los gráficos y el disponible usan esos mismos montos mensuales. Los antiguos importes reales se conservan en el almacenamiento, pero no se suman otra vez.

Actualiza en el mismo repositorio y dirección. Se conserva aureoV16. No borres los datos del navegador.
