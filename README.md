# Áureo 3.2.7

Aplicación sin presupuesto precargado: no incluye ingresos, egresos, inversiones, metas ni conceptos personales en el código. Para una visita nueva comienza en cero. Los datos existentes permanecen en localStorage del navegador y no se envían a un servidor por la aplicación.

## Actualización
Reemplaza index.html y service-worker.js en el mismo repositorio y dirección de publicación. No borres los datos del navegador ni desinstales la aplicación: allí está el presupuesto existente.

## Archivos públicos anteriores
Reemplazar la versión actual no elimina el historial de GitHub, ZIPs o archivos antiguos que se hayan subido al repositorio. Es necesario retirar esos archivos y limpiar el historial para dejar de ofrecer públicamente los datos anteriores. Esto no puede revocar copias ya descargadas por terceros.
